# 余烬回廊 MVP0.14 · 遗迹首页背景

试玩：https://ywb822ovo.github.io/ember-corridor-game/?v=0.14

开始游戏首页使用用户指定的遗迹概念插画，原图不改绘。标题与操作集中在左侧暗部，保留右侧旅人和石门；背景仅用于首页，选关、仓库、设置和战斗沿用既有界面。

电脑：WASD／方向键移动，自动瞄准射击，E交互，Esc暂停。手机：页面内自动横向显示，左摇杆移动、按住攻击、点击情境交互，右上暂停；无需浏览器支持方向锁定。沿用0.13的触控和旋转菜单处理。

网址域名和路径、存档键均不变，?v=0.14只帮助载入新版入口。武器选择、解锁和结算记录仍在当前浏览器；不同设备与旧Sites网址的记录分开，可导入导出。未结束战斗不跨刷新保存。

本轮没有调整战斗数值或开发第二／第三章新内容。第三章、完整逃离、云存档和联机仍未制作。

程序、界面与首页概念图由AI辅助制作；第三方素材来源和许可见THIRD_PARTY_NOTICES.md。概念插画不作为实机画面或已完成关卡证明。浏览器模拟检查不能替代手机微信真机测试。

纯静态网页，无后端和API密钥；GitHub Pages从main根目录发布。公开文件不含课程报告、成员个人资料、存档和测试截图。
