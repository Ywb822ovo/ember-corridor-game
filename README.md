# 余烬回廊 MVP0.15 · 居中首页

试玩：https://ywb822ovo.github.io/ember-corridor-game/?v=0.15

首页使用既有用户指定插画，采用cover铺满并右下对齐，保留右侧旅人；修正较高窗口中人物被居中裁掉的问题。游戏名和主菜单居中，桌面标题64px、开始24px、其他菜单20px，手机标题38—42px、开始22px、其他菜单16px。中部局部暗化保持文字可读。

电脑：WASD／方向键移动，自动瞄准射击，E交互，Esc暂停。手机：页面内自动横向显示，左摇杆移动、按住攻击、点击情境交互，右上暂停；无需浏览器支持方向锁定。触屏与菜单手势沿用既有实现。

GitHub网址的域名、路径和存档键不变；?v=0.15用于载入新版入口。装备选择、章节解锁与结算记录保存在当前浏览器，不同设备可导入／导出转移；未结束战斗不跨刷新保存。

本轮只调整首页HTML文字与CSS，不修改战斗数值和其他页面。第三章、完整逃离、云存档和联机仍未制作。
