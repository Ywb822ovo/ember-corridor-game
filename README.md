# 余烬回廊 · 1.0阶段体验版

[在线试玩](https://ywb822ovo.github.io/ember-corridor-game/?v=1.0-map.1)

本次发布版本为 `1.0-map.1`，对应开发提交 `a1afaeb6d80789b0e582b5e4226ee8675cfe394d`。原生HTML/CSS/JavaScript与Canvas 2D实现，无构建步骤。

包含两章普通/困难模式、第一章可输入种子复现的随机探索、随机敌人组合与奖励、工坊环境机关及双阶段首领。首页使用轻量SVG旅人，背景音乐按场景播放；小地图使用主角头像、通关连线、火焰补给图标和恶魔首领图标，靠近服务角色可交谈。

电脑：WASD／方向键移动，默认鼠标瞄准、自动射击；设置可切换自动瞄准。E交谈／交互，Esc关闭对话或暂停。手机：左摇杆移动，按住攻击默认自动瞄准，情境按钮交互；页面支持固定竖屏浏览器内的横向舞台。

原GitHub网址、路径和存档键 `last-five-waves.profile.v1` 保持。装备、设置、章节解锁与已结算记录保存在当前浏览器，可导入／导出；未结束战斗不跨刷新保存。不同设备或网址的存档分别保存。

这是本阶段收尾发布，游戏仍保留“1.0开发版”标识。第三章和完整逃离结局、云存档及联机尚未制作。强化配装的第二章首领过载阶段可能短于设计目标，未宣称所有配置已完成平衡。

开发版294项Node规则测试通过；桌面与手机横屏／固定竖屏浏览器模拟已检查。自动化检查不等于真人试玩、手机真机或微信内核验收，也不保证各地区网络连通性。

程序、界面、地图与新增图形由AI辅助设计和开发；第三方图集、地图与音乐保留作者和许可，见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。不将第三方作品表述为学生或AI原创。
