# 余烬回廊 / Ember Corridor

课程数字游戏试玩原型，MVP0.12。两章俯视角地牢射击，支持电脑与手机横屏操作。

## 操作

- 电脑：WASD／方向键移动，自动瞄准与射击，E交互，Esc暂停。
- 手机：左侧摇杆移动，按住右侧攻击键射击并自动瞄准；交互键用于传送、商店、休息和控制台。
- 竖屏进入战斗先暂停，转横屏后点击继续。设置和章节进度保存在当前浏览器，可导入、导出备份，未结束战斗不跨刷新保存。

原型尚未包含第三章、云存档、联机或完整逃离结局。程序检查和浏览器模拟不代表手机真机测试或难度已平衡。

## 发布
