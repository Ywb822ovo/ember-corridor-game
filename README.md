# 余烬回廊 MVP0.13 · 页面内自动横屏

新版试玩：https://ywb822ovo.github.io/ember-corridor-game/?v=0.13

这是两章地牢射击课程原型。手机打开后，页面会直接以横向游戏布局显示首页、选关与战斗；浏览器保持竖屏也可游玩，不再显示必须旋转手机的阻断页面，不依赖屏幕方向锁定或全屏。

## 操作

- 手机：左侧摇杆移动，按住右侧攻击键射击并自动瞄准，蓝色交互键用于传送、商店、休息和机关，右上暂停。页面旋转显示时，摇杆和菜单滑动方向同步转换；可侧着拿手机观看，浏览器自身无需成功切换方向。
- 电脑：WASD／方向键移动，自动瞄准与射击，E交互，Esc暂停。
- 手机实际横屏时恢复正常横屏排布；尺寸变化时清空当前触摸，松手后重新操作即可，不因横竖提示而暂停。切后台、失焦的暂停行为保留。

## 进度与范围

网址的域名和路径不变，本地存档键不变；?v=0.13仅帮助载入新版入口，不改变存档位置。不清除原GitHub网址的武器选择、章节解锁或结算记录。不同浏览器、设备和旧Sites网址的记录仍各自保存，可导入／导出转移。未结束战斗不跨刷新保存。

本轮只修复横屏显示与触摸兼容，没有更改战斗数值。第三章、云存档、联机和完整逃离结局仍未制作。
