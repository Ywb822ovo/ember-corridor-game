BEFORE YOU SET OUT

游戏说明

误入地下城，寻找逃离的出口。

01 / 操作

你走位，武器开火。

小地图上，主角头像标记当前位置；亮线连接已完成的相邻房间。火焰表示休息与交易据点，恶魔头像表示首领。普通房和精英房不显示类型文字。靠近人物后可交谈，选择交易或恢复。

电脑：WASD或方向键移动，默认鼠标瞄准、自动射击；可在设置切回自动瞄准。
E：服务、传送或战斗中断电；Esc：暂停。
手机：横屏，左摇杆移动，按住右侧攻击自动瞄准射击；蓝色交互键用于传送、购物、休息和机关。松开攻击即停火。
网页会自动显示横屏游戏，无需浏览器支持屏幕旋转。切后台仍会暂停。

首页开始游戏后选择章节与难度。通关第一章普通，同时解锁本章困难和第二章普通；通关第二章普通，解锁第二章困难。

怪物显示真实数值血条，精英条更厚。命中显示伤害；霰弹同轮命中同一目标合并。

02 / 第一章

遗迹地牢。

前厅 → 商店 → 塌陷回廊 → 精英回廊 → 休息站 → 遗迹守卫。

利用石柱与墓碑躲弹。击败守卫后走到出口按E，保留装备与强化，恢复2格生命，进入第二章。

03 / 第二章

失落工坊。

入口 → 装配厅 → 补给室或精英车间 → 核心前厅 → 总装监工。可以返回清空房间，不重复刷怪或奖励。

猎犬锁定后扑击，脉冲射手三连发，投雷工匠标记爆点。战斗房共3～4波，每10秒增援，不必等上一波清空。修理无人机蓄力维修同伴，自爆搬运机停住倒计时后爆炸。装配母机每10秒召唤两只近战小机器人；重装冲锋可引向墙壁，撞墙眩晕2秒。电板、冲床、蒸汽、锯片均可伤敌；传送带同时推动双方。控制台E断电4秒、冷却10秒。精英线工牌开启隐藏检修间，零件可购买对应武器的本章临时改造。

04 / 阶段目标

寻找升降梯的动力。

监工依次控制竖列激光、边缘弹幕、三连冲压与轨道电束。装甲闭合时承伤50%，每招后核心暴露时承伤150%。33%生命时全厂断电1.5秒，重启后进入核心过载，电板、蒸汽与加速传送带加入战斗。

第二章出口结算为“阶段完成”，第三章地底熔窟尚未开放。进入工坊后，失败可恢复入口装备重试；刷新网页不保留进行中的战斗。旧版战绩保留。
