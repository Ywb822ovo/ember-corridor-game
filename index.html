BEFORE YOU SET OUT

游戏说明

误入地下城，寻找逃离的出口。

01 / 操作

你走位，武器开火。

电脑：WASD或方向键移动，自动瞄准与射击。
E：服务、传送或战斗中断电；Esc：暂停。
手机：横屏，左摇杆移动，按住右侧攻击自动瞄准射击；蓝色交互键用于传送、购物、休息和机关。松开攻击即停火。
竖屏或切后台会暂停，横屏后点击继续。

首页开始游戏后选择章节与难度。通关第一章普通，同时解锁本章困难和第二章普通；通关第二章普通，解锁第二章困难。

怪物显示真实数值血条，精英条更厚。命中显示伤害；霰弹同轮命中同一目标合并。

02 / 第一章

遗迹地牢。

前厅 → 商店 → 塌陷回廊 → 精英回廊 → 休息站 → 遗迹守卫。

利用石柱与墓碑躲弹。击败守卫后走到出口按E，保留装备与强化，恢复2格生命，进入第二章。

03 / 第二章

失落工坊。

入口 → 装配厅 → 补给室或精英车间 → 核心前厅 → 总装监工。可以返回清空房间，不重复刷怪或奖励。

猎犬锁定后扑击，脉冲射手三连发，投雷工匠标记爆点。重装执卫装甲减伤、核心暴露时易伤。电板和冲床也能伤敌；控制台E断电4秒，冷却10秒。护盾可以挡机械机关。

04 / 阶段目标

寻找升降梯的动力。

监工使用电束、三连落锤与小兵召集；召集期间停止自身攻击，清掉小兵后核心暴露。

第二章出口结算为“阶段完成”，第三章地底熔窟尚未开放。进入工坊后，失败可恢复入口装备重试；刷新网页不保留进行中的战斗。旧版战绩保留。
